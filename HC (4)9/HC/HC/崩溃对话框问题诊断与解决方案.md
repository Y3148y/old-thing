# 崩溃对话框问题诊断与解决方案

## 问题描述
应用闪退后无法弹出包含崩溃详情的对话框，需要检查弹出权限以及触发机制。

## 问题原因分析

### 1. Android版本兼容性问题
- **Android 6.0 (API 23) 以下**：可以直接使用 `TYPE_SYSTEM_ALERT`
- **Android 6.0+ (API 23+)**：需要动态申请 `SYSTEM_ALERT_WINDOW` 权限
- **Android 8.0+ (API 26+)**：必须使用 `TYPE_APPLICATION_OVERLAY` 替代 `TYPE_SYSTEM_ALERT`

### 2. 权限配置问题
- AndroidManifest.xml 中缺少 `SYSTEM_ALERT_WINDOW` 权限声明
- 用户未授予悬浮窗权限
- 应用上下文不正确

### 3. 线程和生命周期问题
- 崩溃时主线程可能已经停止
- Context 可能已经无效
- Looper 准备不当

## 解决方案

### 1. 权限配置

#### AndroidManifest.xml 权限声明
```xml
<!-- 系统弹窗权限 (用于崩溃对话框) -->
<uses-permission android:name="android.permission.SYSTEM_ALERT_WINDOW" />
```

#### 动态权限检查和申请
在 MainActivity 中添加权限检查：
```java
private static final int REQUEST_OVERLAY_PERMISSION = 1001;

private void checkOverlayPermission() {
    if (Build.VERSION.SDK_INT >= Build.VERSION_CODES.M) {
        if (!Settings.canDrawOverlays(this)) {
            // 请求悬浮窗权限
            Intent intent = new Intent(Settings.ACTION_MANAGE_OVERLAY_PERMISSION,
                    Uri.parse("package:" + getPackageName()));
            startActivityForResult(intent, REQUEST_OVERLAY_PERMISSION);
        }
    }
}

@Override
protected void onActivityResult(int requestCode, int resultCode, Intent data) {
    super.onActivityResult(requestCode, resultCode, data);
    if (requestCode == REQUEST_OVERLAY_PERMISSION) {
        if (Build.VERSION.SDK_INT >= Build.VERSION_CODES.M) {
            if (Settings.canDrawOverlays(this)) {
                Toast.makeText(this, "悬浮窗权限已获取，崩溃对话框将正常显示", Toast.LENGTH_SHORT).show();
            } else {
                Toast.makeText(this, "悬浮窗权限被拒绝，崩溃对话框可能无法显示", Toast.LENGTH_LONG).show();
            }
        }
    }
}

// 在 onCreate 方法中调用
@Override
protected void onCreate(Bundle savedInstanceState) {
    super.onCreate(savedInstanceState);
    setContentView(R.layout.activity_main);
    
    // 检查悬浮窗权限
    checkOverlayPermission();
    
    // 初始化崩溃处理器
    CrashHandler.getInstance().init(this);
}
```

### 2. CrashHandler 优化

#### 完整的崩溃对话框实现
```java
private void showCrashDialog(Context context, String crashInfo) {
    try {
        AlertDialog.Builder builder = new AlertDialog.Builder(context);
        builder.setTitle("应用崩溃");
        builder.setMessage(crashInfo);
        builder.setCancelable(false);
        
        // 设置按钮
        builder.setPositiveButton("确定", (dialog, which) -> {
            dialog.dismiss();
            android.os.Process.killProcess(android.os.Process.myPid());
        });
        
        builder.setNegativeButton("复制日志", (dialog, which) -> {
            copyToClipboard(context, crashInfo);
            dialog.dismiss();
            android.os.Process.killProcess(android.os.Process.myPid());
        });
        
        AlertDialog dialog = builder.create();
        
        // 根据Android版本动态设置窗口类型
        if (Build.VERSION.SDK_INT >= Build.VERSION_CODES.O) {
            // Android 8.0+ 使用 TYPE_APPLICATION_OVERLAY
            dialog.getWindow().setType(WindowManager.LayoutParams.TYPE_APPLICATION_OVERLAY);
        } else if (Build.VERSION.SDK_INT >= Build.VERSION_CODES.M) {
            // Android 6.0+ 检查悬浮窗权限
            if (Settings.canDrawOverlays(context)) {
                dialog.getWindow().setType(WindowManager.LayoutParams.TYPE_SYSTEM_ALERT);
            } else {
                // 无权限时使用应用内对话框
                dialog.getWindow().setType(WindowManager.LayoutParams.TYPE_APPLICATION_ATTACHED_DIALOG);
            }
        } else {
            // Android 6.0 以下直接使用 TYPE_SYSTEM_ALERT
            dialog.getWindow().setType(WindowManager.LayoutParams.TYPE_SYSTEM_ALERT);
        }
        
        dialog.show();
    } catch (Exception e) {
        Log.e(TAG, "显示崩溃对话框失败: " + e.getMessage(), e);
        // 备用方案：使用Toast显示崩溃信息
        try {
            Toast.makeText(context, "应用崩溃，请查看日志文件", Toast.LENGTH_LONG).show();
        } catch (Exception toastException) {
            Log.e(TAG, "Toast显示也失败: " + toastException.getMessage(), toastException);
        }
    }
}
```

### 3. 触发机制检查

#### 崩溃处理流程

## 常见问题和解决方案

### 问题1：对话框不显示
**可能原因**：
- 没有悬浮窗权限
- Context 无效
- 窗口类型不正确

**解决方案**：
- 检查并申请悬浮窗权限
- 使用 ApplicationContext
- 根据 Android 版本选择正确的窗口类型

### 问题2：日志文件未生成
**可能原因**：
- 存储权限不足
- 目录创建失败
- 异常处理被跳过

**解决方案**：
- 检查存储权限
- 确保目录创建逻辑正确
- 添加更多日志输出

### 问题3：应用立即退出
**可能原因**：
- `System.exit(1)` 被过早调用
- 线程休眠时间不足

**解决方案**：
- 增加线程休眠时间到 5-10 秒
- 确保对话框有足够时间显示
