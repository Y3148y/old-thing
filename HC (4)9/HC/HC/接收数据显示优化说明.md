# 接收数据显示优化说明

## 功能概述

本次修改优化了蓝牙应用中接收数据的显示逻辑，将原来无限制追加数据的方式改为只保存最近四次命令的显示方式，提升了用户体验和应用性能。

## 主要改进

### 1. 数据量控制
- **硬编码限制**：设置 `MAX_COMMANDS = 4`，只保存最近4次接收到的命令
- **自动清理**：当接收到新命令时，自动移除最早的命令，保持显示内容简洁
- **内存优化**：避免了长时间运行导致的数据累积和内存占用问题

### 2. 智能数据管理
- **过滤机制**：自动过滤空行和默认提示文本（"等待接收数据..."）
- **动态更新**：每次接收新数据时重新构建显示内容
- **状态保持**：当没有命令时自动显示默认提示信息

### 3. 用户体验优化
- **界面简洁**：始终只显示最相关的最新4条命令
- **滚动优化**：保持自动滚动到底部的功能，确保最新数据可见
- **格式统一**：统一的换行和格式处理，提供一致的显示效果

## 技术实现细节

### 核心算法
```java
// 1. 获取当前显示内容并按行分割
String currentText = mReceiveContent.getText().toString();
String[] lines = currentText.split("\n");

// 2. 创建命令列表并过滤有效内容
java.util.List<String> commandList = new java.util.ArrayList<>();
for (String line : lines) {
    if (!line.trim().isEmpty() && !line.equals("等待接收数据...")) {
        commandList.add(line.trim());
    }
}

// 3. 添加新命令
String newCommand = a.trim();
if (!newCommand.isEmpty()) {
    commandList.add(newCommand);
}

// 4. 维护最大数量限制
while (commandList.size() > MAX_COMMANDS) {
    commandList.remove(0); // 移除最早的命令
}

// 5. 重新构建显示文本
StringBuilder displayText = new StringBuilder();
if (commandList.isEmpty()) {
    displayText.append("等待接收数据...");
} else {
    for (int i = 0; i < commandList.size(); i++) {
        displayText.append(commandList.get(i));
        if (i < commandList.size() - 1) {
            displayText.append("\n");
        }
    }
}

// 6. 更新TextView内容
mReceiveContent.setText(displayText.toString());
```

### 关键特性

1. **FIFO队列机制**：采用先进先出的队列逻辑，确保显示的是最新的4条命令
2. **实时更新**：每次接收到新数据都会重新计算和更新显示内容
3. **异常安全**：在原有的异常处理框架内工作，确保稳定性
4. **线程安全**：在UI线程中执行更新操作，避免并发问题
