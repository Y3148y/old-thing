## 异常处理设计原则

### 1. 统一异常记录
- 所有异常通过`CrashHandler.logException`进行统一记录
- 便于问题追踪和分析
- 支持异常统计和监控

### 2. 详细日志输出
- 每个异常包含具体错误信息和上下文
- 使用`Log.e`记录错误级别日志
- 包含方法名和操作描述

### 3. 用户友好提示
- 在适当位置向用户显示错误提示
- 避免技术性错误信息直接暴露给用户
- 提供操作建议和解决方案

### 4. 不影响主流程
- 异常处理不阻断应用正常运行
- 优雅降级，保证核心功能可用
- 避免因局部异常导致整体崩溃

## 代码示例

### 典型异常处理模式

```java
private void initReceiver() {
    try {
        // 核心业务逻辑
        mBLuetoothStateReceiver = new BroadcastReceiver(){
            @Override
            public void onReceive(Context context, Intent intent) {
                try {
                    // 具体操作
                } catch (Exception e) {
                    Log.e(TAG, "蓝牙状态广播接收异常: " + e.getMessage());
                    CrashHandler.logException("蓝牙状态广播接收异常", e);
                }
            }
        };
        
        Log.d(TAG, "initReceiver初始化成功");
    } catch (Exception e) {
        Log.e(TAG, "initReceiver初始化异常: " + e.getMessage());
        CrashHandler.logException("initReceiver初始化异常", e);
    }
}
```
