# 蓝牙权限配置说明

## 权限配置概览

本应用已完成蓝牙权限的全面配置，支持不同Android版本的权限要求：

### 1. AndroidManifest.xml 权限配置

#### 基础蓝牙权限
- `BLUETOOTH` - 基础蓝牙功能
- `BLUETOOTH_ADMIN` - 蓝牙管理权限
- `ACCESS_FINE_LOCATION` - 精确位置权限（蓝牙扫描需要）
- `ACCESS_COARSE_LOCATION` - 大致位置权限

#### Android 12+ (API 31+) 新权限
- `BLUETOOTH_SCAN` - 蓝牙扫描权限（使用neverForLocation标志避免位置权限）
- `BLUETOOTH_CONNECT` - 蓝牙连接权限
- `BLUETOOTH_ADVERTISE` - 蓝牙广播权限

#### Android 13+ (API 33+) 附近设备权限
- `NEARBY_WIFI_DEVICES` - 附近WiFi设备权限（使用neverForLocation标志）

### 2. 动态权限请求

应用会根据Android版本自动请求相应权限：

- **Android 6.0-11**: 请求位置权限
- **Android 12**: 请求蓝牙扫描、连接权限 + 位置权限
- **Android 13+**: 请求蓝牙扫描、连接权限 + 附近设备权限

### 3. 权限检查机制

在执行蓝牙操作前，应用会自动检查权限状态：
- 开启蓝牙前检查权限
- 搜索设备前检查权限
- 连接设备前检查权限

### 4. 用户友好的权限反馈

权限请求结果会以中文形式显示：
- 蓝牙扫描权限
- 蓝牙连接权限
- 附近设备权限
- 精确位置权限
- 大致位置权限

## 使用建议

1. **首次启动**: 应用会自动请求所需权限，建议全部授予以确保功能正常
2. **权限被拒绝**: 如果权限被拒绝，可以在系统设置中手动授予
3. **Android 12+**: 使用了neverForLocation标志，减少了对位置权限的依赖
4. **兼容性**: 支持Android 6.0及以上所有版本

## 故障排除

如果蓝牙功能异常，请检查：
1. 设备是否支持蓝牙
2. 蓝牙是否已开启
3. 应用权限是否已授予
4. Android版本是否支持

## 技术实现

- 使用`ActivityCompat.requestPermissions()`动态请求权限
- 使用`ActivityCompat.checkSelfPermission()`检查权限状态
- 根据`Build.VERSION.SDK_INT`适配不同Android版本
- 使用`neverForLocation`标志优化用户体验
